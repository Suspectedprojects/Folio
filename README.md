# Folio

A lightweight file explorer for Windows whose thumbnails can be **any size you like**, from 32 px up to 1600 px.

## Why it exists

Windows File Explorer tops out at "Extra large icons", which is 256 × 256 px, and there's no setting to go bigger. That's too small for browsing folders of photos and scans on a large screen. Folio was made to fix exactly that one thing while keeping the everyday Explorer features you rely on, without the bloat of a full image manager.

## Features

- **Freely sizable thumbnails.** Use the slider, hold Ctrl and scroll the mouse wheel, or press Ctrl and + / −. Thumbnails are rendered fresh at the chosen size rather than stretched.
- **The same thumbnails as Explorer.** Folio asks Windows for them, so photos, videos, PDFs, documents and folder previews all work.
- **Fast with huge folders.** Only the items on screen are created, thumbnails load in the background, newest requests first, and memory use is capped.
- **Thumbnails and details views**, with natural sort by name, date, type or size.
- **The real Windows right-click menu**, including Open with, Send to, Properties and add-ons like 7-Zip.
- **Copy, cut, paste, rename, delete and new folder**, using Windows' own progress and conflict dialogs. Delete goes to the Recycle Bin, and Shift+Del deletes permanently. Copy/paste works with File Explorer in both directions.
- **Drag and drop** to and from other apps.
- **Navigation.** Back, forward and up; an editable address bar; mouse side buttons; a folder tree with Quick access and drives.
- **Search** that filters as you type, with an option to search all subfolders.
- **Automatic refresh** when files change, hidden-file and file-extension toggles, Open in Terminal, and multiple windows (Ctrl+N).
- **Follows the Windows light or dark theme**, and remembers your settings.

## Install

1. Download **`Folio-x.y.z.msi`** from the [latest release](https://github.com/Suspectedprojects/Folio/releases/latest).
2. Run it. Folio installs for your user account only, so no administrator rights are needed. It goes in `%LOCALAPPDATA%\Programs\Folio` and adds a Start menu shortcut.
3. Uninstall it any time from **Settings → Apps → Installed apps**.

The installer isn't code-signed, so Windows SmartScreen may warn you the first time you run it. Choose **More info → Run anyway**.

The app is self-contained, so you don't need to install .NET separately. It requires Windows 10 or 11, 64-bit.

## Build from source

You need the [.NET 10 SDK](https://dotnet.microsoft.com/download).

```powershell
# run the app
dotnet run --project Folio -c Release

# build the self-contained exe and the .msi into .\artifacts
.\build.ps1 -Version 1.0.0
```

The installer is built with [WiX Toolset](https://wixtoolset.org/), which is pulled in automatically as a NuGet SDK. The icon is drawn by `Folio/tools/make-icon.ps1`.

## How it works

| File | What it does |
|---|---|
| `Folio/Shell.cs` | Gets thumbnails through `IShellItemImageFactory` at any pixel size, shows the shell context menu through `IContextMenu`, and does file operations through `SHFileOperation` |
| `Folio/VirtualizingTilePanel.cs` | A virtualizing wrap panel for the thumbnail grid |
| `Folio/ThumbnailLoader.cs` | Background STA worker threads that load thumbnails, last-in first-out |
| `Folio/FileItem.cs` | Loads thumbnails lazily and keeps decoded images within a memory budget |
| `Folio/MainWindow.xaml(.cs)` | The UI, navigation, search, clipboard and drag & drop |
| `installer/` | The WiX project for the per-user `.msi` |
